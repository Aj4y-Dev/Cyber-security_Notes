### What is a Bug Bounty Program (BBP)?

A **Bug Bounty Program** is a crowdsourced security initiative where organizations reward security researchers for finding and responsibly reporting vulnerabilities.

It is also known as a **Vulnerability Rewards Program (VRP)**.

BBPs provide **continuous and proactive security testing**, complementing:
- Internal code reviews
- Penetration tests
- Vulnerability management processes

> HackerOne describes this as **“Continuous testing, constant protection”**, integrated into the software development lifecycle.

## Types of Bug Bounty Programs

### 1. Private Bug Bounty Programs

- Not publicly accessible
- Invitation-only
- Usually the **starting phase** of most programs
- Invitations based on:
    - Past valid reports
    - Consistency
    - Low violation record
- Some programs may require **background checks**

### 2. Public Bug Bounty Programs

- Open to **everyone**
- Accessible to the entire hacking community
- No invitation required

### 3. Parent / Child Programs

- Used by large organizations
- A **parent company** and its **subsidiaries** share:
    - One bounty pool
    - One security team
- Subsidiary programs are linked to the parent program
